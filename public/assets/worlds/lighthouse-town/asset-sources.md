# 灯塔镇视觉资产来源

`tileset.svg` 与 `residents.svg` 是本项目为灯塔镇原创的确定性像素矢量资产，由 `scripts/generate-lighthouse-assets.mjs` 在 2026-07-14 生成。

制作要求：32 像素网格、江南水乡建筑、中央灯塔、黛青/米白/朱砂/暖灯黄配色、九个四方向人物槽位。资产没有复制或描摹第三方图像，也没有包含商标、受限字体或外部素材。

重新生成：

```bash
node scripts/generate-lighthouse-assets.mjs
```

生成脚本和输出随本项目按 MIT 许可证分发。上游 AI Town 自带但未被这些文件复制的资产仍遵循其原始署名和许可证说明。

## Image 2 视觉参考

- `docs/visuals/lighthouse-town-concept-v1.png`：使用内置 Image 2 于 2026-07-15 生成的氛围与配色参考。提示词要求暮色江南水镇、中央内陆灯塔、拱桥水巷、荷塘、八个生活区域、黛青与暖金对比，不包含商标、水印或可读文字。
- `event-poster-v1.png`：使用内置 Image 2 于 2026-07-15 生成的无字赛事公告插画。画面包含恰好八位虚构参赛者、金贝、拱桥和远处灯塔；赛事标题与规则由网页文字叠加。
- `playable-map-v1.webp`：使用内置 Image 2 把概念图重绘成严格俯视、4:3 的可玩像素地图，按中央灯塔、十字主路、双河道、石桥与六处生活区域构图；原始 PNG 保留在 Codex 生成目录，运行时使用 685KB WebP。
- `trial-island-v1.jpg`：使用内置 Image 2 于 2026-07-19 生成的试炼岛右侧地图段。以 `playable-map-v1.webp` 仅作画风参考，要求严格俯视、左侧八格内河水面、江南园林岛，以及码头、跑道、踏石桥、庭院、双队场、迷宫、物资区、观众席和颁奖广场；明确排除文字、人物、海洋、航标、神秘异变和魔法效果。原始 1518×1036 PNG 保留在 Codex 生成目录，运行时资产按 44×30 个 32 像素格缩放为 1408×960、JPEG 质量 90。
- 碰撞、寻路和人物动画使用确定性的 84×30 总网格（40×30 主镇、8×30 隔离河道、36×30 试炼岛）；Image 2 地图作为真实游戏画布环境层接入，而不是只留在设计文档中。

## 居民真人影像

`residents/<居民 id>/portrait.webp`、`work.webp`、`life.webp` 与 `social.webp` 于 2026-07-15 至 2026-07-16 使用内置 Image 2 生成。每位居民先生成一张保持同一成年身份、面孔、发型与服饰的 2×2 真人摄影联络表，四格分别表现人物近照、工作、日常生活与社交关系，再在本地等分裁切并转换为 WebP 运行时资产。

影像中的居民及同框人物均为 AI 虚构成年人，不以真人、名人或受保护角色为原型。生成要求明确排除可读文字、标志、水印与现代物件；人物身份、服装、职业、关系和灯塔镇江南水乡环境取自 `data/worlds/lighthouse-town/lives.ts` 与 `characters.ts`。
