# 灯塔镇双日报与历史赛事展示设计

## 目标

观察台提供两种彼此独立的 Markdown 日报：

1. **事实流水账**：保留现有完整观察日报，逐项记录人物、关系设定、地点、活动、对话和原始材料，不作社会解释。
2. **社会观察日志**：在同一批当日本地记录上生成中等篇幅的结构化观察，帮助长期追踪灯塔镇的社会发展，但不替用户形成论文结论。

已结束的百万金贝赛事不再以直播或当前活动呈现，只作为过去的公共事件档案。每日新活动的直播、归档与地图规则由 [每日活动与试炼岛地图系统设计](./2026-07-17-daily-event-map-system-design.md) 定义；只有当日 12:00–14:00 正在举行的新活动可显示直播。

## 已选方案

采用同一张导出卡片中的两个并列按钮：

- `导出事实流水账`
- `生成社会观察日志`

该方案比下拉菜单更直观，又比两张独立卡片节省观察台空间。生成社会观察日志时按钮显示明确的处理中状态，避免重复提交。

## 事实流水账

现有 `buildDailyReport` 的事实边界保持不变：

- 使用上海时区筛选当日记录。
- 覆盖已加载的最多 500 条消息和 500 条生活记录。
- 明确区分人物设定、当日事实和观察者介入。
- 保留完整原始对话与生活记录附录。
- 不推断动机、因果或研究结论。

文件名改为更明确的 `灯塔镇事实流水账-YYYY-MM-DD.md`。

## 社会观察日志

社会观察日志为约 1500–2500 字的中等研究记录，包含：

1. 观察范围与数据覆盖
2. 当日社会结构概览
3. 居民互动网络与关系动向
4. 友情、亲密关系与合作迹象
5. 商业生活、劳动与机构使用
6. 公共生活、规范、分歧与协调
7. 观察者介入及其可见影响
8. 本地模型辅助的谨慎观察
9. 后续值得持续记录的线索
10. 方法与边界说明

程序先从事实快照生成可复核的统计摘要，例如互动次数、共同对话伙伴、地点使用、生活活动、公共日志和观察者介入。统计摘要是社会日志的事实骨架。

本地 `gemma4:12b` 只接收有长度上限的事实摘要，并生成谨慎的观察文字。提示词要求：

- 只能使用摘要中的事实。
- 使用“记录显示”“可能”“尚需持续观察”等限定表达。
- 不补写不存在的事件、关系或动机。
- 不作心理诊断、价值评判、因果定论或论文结论。
- 明确区分人物设定与当日观察。

本地模型不可用、超时或返回无效内容时，系统直接导出程序生成的统计观察版，并在方法说明中标明“本次未使用模型扩写”。不调用 DeepSeek 或其他付费 API。

## 数据流与边界

1. 浏览器继续读取现有 `observerSnapshot`，不新增数据库表。
2. 客户端从快照生成当日社会统计和一个有长度上限的事实摘要。
3. 用户点击社会观察按钮后，Convex action 将摘要交给本地 Ollama。
4. action 返回模型观察文字或失败状态。
5. 客户端把稳定统计、模型观察或回退说明组合成 Markdown 并下载。

报告不持久化到新表，不新增后台定时任务，不自动生成，不打包 ZIP。只有用户点击时才生成。

暂停小镇会停止居民的自主行动和新推理请求；用户手动点击社会观察日志属于明确的人工请求，仍可调用已常驻的 Gemma。Ollama 的模型常驻设置与小镇暂停状态互不删除、互不卸载。

## 历史赛事展示

当赛事状态为已结束时：

- 观察台不再使用“赛事直播”措辞。
- 不显示实时排行榜、剩余人数、参赛中角色或倒计时。
- 展示区名称改为“往届赛事记录”。
- 仅显示赛事名称、冠军、奖励、最终结果和历史过程日志。
- 居民当前状态继续来自正常生活系统，不再由赛事身份覆盖。
- 事实流水账将赛事放入“历史公共事件”。
- 社会观察日志只把赛事标记为历史背景，不计入当天社会活动，除非当天确有新的纪念或回顾记录。

## 错误处理

- 模型生成期间禁用社会观察按钮并显示“正在整理社会观察”。
- 模型失败不阻止下载，自动输出统计回退版。
- 空数据统一写“当日无记录”，不制造解释。
- 动态文本继续经过 Markdown/HTML 转义。
- 观察者姓名冲突继续使用固定“观察者”身份，不归入任何居民。

## 测试与验收

- 事实流水账原有测试全部保持通过。
- 社会观察日志包含规定章节、上海日期和事实统计。
- 模型提示词只包含有界事实摘要，并明确禁止虚构和定论。
- Ollama 成功时组合模型观察；失败时导出统计回退版。
- 已结束赛事页面不出现直播、倒计时、剩余人数或实时排名。
- 已结束赛事仍保留冠军、奖励和历史过程记录。
- 两个按钮均生成正确的中文文件名。
- 全量单元测试、TypeScript、生产构建、世界资源校验和真实页面检查通过。

## 非目标

- 不构建论文分析平台、统计数据库或关系图编辑器。
- 不自动写论文、不生成因果结论。
- 不启用付费模型兜底。
- 不恢复已结束赛事的直播状态。
