# 灯塔镇持续生活、活动验收与研究归档设计

## 目标

让灯塔镇在无人打开网页时仍以低资源方式持续发展；电脑休眠或关机后再次启动时有限度地补齐可信事实；手动暂停时真正停止；每日活动能够通过可重复的全流程演练验收；研究资料自动写入一个与 Obsidian 第二大脑完全隔离的 IMA 导入目录；最终把已验证代码整合并上传 Git。

## 核心原则

1. **持续不等于持续调用大模型。** 无观察者时只运行确定性规则，重要对话和复杂决策才调用本地 Gemma。
2. **事实与生成文本分离。** 后台产生的是工作、消费、关系、地点和活动结算事实，不伪造居民对话。
3. **暂停是硬边界。** `stoppedByDeveloper` 期间既不推进，也不在恢复后补算。
4. **离线补算有上限。** 电脑休眠或关机后按离散时间槽补算，避免一次恢复制造无限记录或压垮电脑。
5. **研究档案与个人知识库隔离。** 只写灯塔镇专属目录，不读写 Obsidian 仓库。
6. **所有推进均可审计和幂等。** 每条规则事实带唯一来源键；重试不会重复发工资、重复消费或重复改变关系。

## 两层持续机制

### 前台实时层

网页有观察者且世界状态为 `running` 时，沿用现有引擎：居民移动、相遇、聊天、进入地点、参加活动。本地 Gemma 仅在对话或重要决策时按需加载。

### 后台生活层

无人观察使世界进入 `inactive` 后，不再保持实时引擎和模型热运行。后台定时任务每五分钟检查一次，以半小时为一个生活时间槽：

- 白天优先产生工作、经营、就餐和购物事实；
- 傍晚优先产生社交、照料与消费事实；
- 夜间只保留少量休息、家庭或必要值守事实；
- 每个时间槽只选择少量居民，避免日志爆炸；
- 所有选择由世界、日期和时间槽确定，可重放、可测试。

持续状态表保存最后处理的时间槽。若机器休眠或关机，下一次后台启动会分批补算遗漏时间槽；详细补算最多覆盖最近七天，更早的空档只写一条明确的“离线空档摘要”，不虚构逐分钟生活。

### 手动暂停

手动暂停将世界置为 `stoppedByDeveloper`。后台只把持续游标推进到当前时间，不产生任何生活事实，因此恢复后也不会把暂停期补回来。暂停时本地模型没有新请求，实时引擎停止。

## 后台事实与经济社会系统

后台事实复用既有经济、关系和生命事件表：

- 工作：居民获得工资，机构发生工资支出并记录产出；
- 消费：居民在餐馆、茶庄、药房等机构消费，资金真实转移；
- 社会关系：合作、照料、交易或普通往来改变关系边，但受每日上限约束；
- 地点：事实记录居民使用了哪个真实机构以及用途；
- 生活事件：记录时间、主体、对象、地点、金额、来源键和规则版本。

后台不写入聊天消息表。日报可以据此区分“真实对话”和“后台规则生活事实”。

## 每日活动全流程验收

提供一个加速演练工具，在不等待现实两小时、也不污染正式世界的情况下完整运行：报名与集合、渡船、组队、各比赛阶段、安全淘汰、观赛、结算奖励、颁奖、返程、恢复日常生活和历史归档。工具输出机器可读结果，并断言：

- 参赛居民、地图检查点和阶段顺序完整；
- 淘汰没有死亡或伤害状态；
- 奖金只结算一次；
- 所有人最终返回主镇并恢复正常生活；
- 旧赛事只作为历史记忆，不重新激活。

这是一套运行规则的端到端排练，补充已有单元测试，不用伪造正式日期记录。

## IMA 独立研究档案

后台归档服务定期从 Convex 读取当日及前一日快照，原子写入专属目录：

`~/Documents/灯塔镇研究档案/IMA导入/`

每个上海自然日包含：

- `事实流水账.md`：人物行动、地点、经济流水、关系变化、活动阶段与原始对话索引；
- `社会观察素材.md`：基础统计、关系网络变化、机构运行、财富与活动影响，明确区分事实和待分析项；
- `原始数据.json`：论文复核所需结构化记录；
- `manifest.json`：世界、日期、生成时间、记录数量和格式版本。

服务每十分钟覆盖更新同一天文件，使用临时文件后重命名，避免半写入。它不访问 Obsidian、不上传第三方、不包含 API 密钥。用户只需在 IMA 中把该文件夹作为资料来源；若当前 IMA 客户端只支持手工导入，文件仍会自动持续更新并保持随时可导入。

## 站点与进程

站点安装脚本管理三个互不抢端口的后台会话：

- Convex 后端；
- `4174` 前端站点；
- 无端口的研究归档循环。

健康检查分别验证前端、后端和归档心跳。归档故障不阻止小镇生活，但会清楚报告，不静默丢失。

## Git 整合

在功能分支上合并主开发分支的最新变化，保留双方历史，不强推。通过类型检查、全量测试、活动排练、归档导出、站点健康和浏览器验收后，推送 `codex/daily-town-implementation`；远端与认证允许时创建合并请求。

## 验收标准

- 无浏览器观察时，后台规则会继续产生幂等的生活、经济与关系事实，且不调用大模型。
- 手动暂停后没有新事实、经济结算、活动推进或模型请求；恢复后不补算暂停期。
- 休眠/关机后能有限补算，单次处理量受限。
- 活动演练覆盖地图、奖励、淘汰、返程和归档的完整闭环。
- IMA 专属目录可连续生成双报告和原始数据，Obsidian 零读写。
- 全量验证通过，分支成功上传 Git。
