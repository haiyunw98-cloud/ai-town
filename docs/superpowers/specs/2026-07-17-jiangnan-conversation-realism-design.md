# 灯塔镇江南日常对话真实性设计

## 目标

让九位居民首先像生活在江南内陆小镇的普通人：谈工作、吃喝、衣物、买卖、邻里、友情、感情、休息和公共事务。灯塔只是镇名来源与历史地标，不是海上设施，也不再驱动居民的自主谈话。

本设计解决四个现存问题：

1. 人物目标、秘密和活动普遍围绕雾潮、航路、罗盘与灯塔装置，导致模型不断回到同一谜团。
2. 旧对话记忆会继续把海上叙事带入新对话。
3. 单轮回复过长、舞台说明过多，更像独白而不像交谈。
4. 对话归纳把大量内容压进“河道水位、灯火装置、花木生长、机关结构”四类，进一步放大失真主题。

## 已选择方案

采用“设定源头重写 + 每日话题预算 + 旧记忆隔离 + 输出校验”。

不采用仅修改系统提示词的方案，因为人物目标和记忆仍会把模型拉回旧主题；也不采用删除全部历史记录的方案，因为历史事实与研究档案必须保留。

## 世界语义

- 灯塔镇是江南内陆水乡，有运河、水巷、石桥、乌篷船和普通河埠，没有海。
- 镇中心的“灯塔”是一座因外形得名的历史高塔和公共地标，不承担海上导航、航标、观潮或海防功能。
- 居民自主对话不得使用海面、海潮、潮汐、观潮、航标、海风、海浪、夜航、失落航路、灯塔导航等海洋叙事。
- 河道、水位、灯具、机械、药草仍可作为真实职业内容，但只能在对应职业或明确公共事件中出现，不能成为全镇每天的共同话题。
- 观察者若主动询问海洋或航标，居民应简短纠正“镇上没有海，这座塔只是地标”，然后按人物身份回应，不顺势编造海上设定。

## 日常话题预算

每次自主对话先由规则系统选择一个可审计的话题类别，再交给模型表达。全镇滚动目标比例为：

- 60% 生计与生活：工作、订单、工资、采购、吃饭、衣物、家务、休息、健康、天气对生活的影响。
- 25% 人际关系：友情、约会、关心、误会、合作、竞争、承诺和邻里互助。
- 15% 公共生活：集市、课程、节庆、店铺变化、公共设施、地方消息和安全提醒。
- 0% 自主灯塔谜团。谜团只保留在历史档案，不进入自主话题池。

同一居民最近三次对话不得连续选择同一细分类别。话题记录包含类别、选择时间和相关地点，供日报分析覆盖度，但不要求为每个日常动作调用模型。

## 人物与活动数据

九位居民保留姓名、职业、关系和性格，但重写会进入模型提示的字段：

- `publicDescription` 描述现实职业与公共身份。
- `identity` 描述性格、能力、边界和生活习惯。
- `plan` 改为可完成的日常目标，如经营、备课、送货、接单、照护与储蓄。
- `relationshipHook` 改为友情、商业、师徒、邻里和可能发展的亲密关系。
- `speakingStyle` 保留人物差异，同时加入短句规则。
- `clue` 作为历史设定保留在内容档案，但不再由 `localizedDescriptions` 拼入运行时 `identity`。

`residentActivities` 中涉及雾潮、航标、灯塔装置和反复异常调查的活动全部替换为普通工作、消费、照护、社交与休闲。人物档案中的当前目标、商业状态和近期情况同步改为日常内容，避免 UI 与运行时提示互相矛盾。

## 旧记忆隔离

已有消息、记忆和日报不得删除或改写。它们仍是历史研究资料。

在构造新对话提示时增加独立的记忆选择层：

1. 先照常检索相关记忆。
2. 含有旧海洋叙事、灯塔谜团或高密度异常调查词的记忆不进入自主对话提示。
3. 过滤只影响模型上下文，不修改数据库记录、原始消息或导出日志。
4. 观察者主动问及某段历史时，可在明确的人类介入分支引用，但必须遵守“江南内陆、没有海”的当前设定。

新生成的记忆摘要同样遵守日常话题和短文本规则，不能在总结阶段重新放大被过滤主题。

## 对话形态

- 开场白以 15–45 个中文字符为目标。
- 普通轮次以 20–60 个中文字符为目标，每轮只推进一个意思。
- 告别以 10–35 个中文字符为目标。
- 一次居民对话通常持续 6–12 轮；少数重要谈心可更长，但仍保持短轮次。
- 不使用连续括号舞台说明，不长篇描述自己的动作、环境或内心。
- 允许自然的追问、确认、犹豫、打断、拒绝和换话题。
- 输出超过边界时在完整句末压缩；出现被禁海洋设定时使用与当前话题匹配的确定性日常回复，不再追加一次昂贵模型调用。

观察者直接参与的对话不强制 6–12 轮，但居民回复仍遵守短句和世界语义。

## 归纳与展示

对话归纳标签改为覆盖真实社会生活的分类：劳动、商业、饮食、照护、友情、亲密关系、合作、分歧、学习、公共生活和休闲。职业词不应自动被归为谜团。

观察台速报彻底移除“小镇异变”“线索正在交汇”“河道水位”“灯火装置”“花木生长”“机关结构”等旧谜团标题、标签和固定文案。它们不得因旧消息中出现过相关词语而重新进入实时摘要。

默认标题使用“今日灯塔镇”，并优先归纳谁在工作、交易、吃饭、休息、照顾他人、建立关系或解决日常问题。当天没有足够的新日常事实时显示“暂无新的日常记录”，不得用旧谜团内容填充版面。

历史原始消息仍可在历史记录或导出文件中查阅，但观察台的当前速报只总结改造后的当日生活内容。实时卡片不显示“异变”“调查”“谜团”“线索”等悬疑化措辞，除非未来存在由用户明确创建且正在发生的公共事件；普通河道、灯具、花木和机械维护也只按工作或公共服务归类。

## 错误处理

- 模型返回空内容：使用当前话题类别的短日常备用句。
- 模型返回过长内容：按句子边界压缩，不截断 Unicode 字符。
- 模型返回海洋设定：拒绝该文本并使用短日常备用句，同时记录不含正文的校验计数。
- 话题池暂时无候选：回退到吃饭、休息、采购或询问近况等普通类别。

## 测试与验收

1. 世界提示明确“江南内陆、没有海、灯塔只是地标”。
2. 九位居民的运行时身份和计划不含海潮、航标、夜航、失落航路或自主灯塔调查目标。
3. `clue` 仍存在于内容档案，但不进入 `localizedDescriptions` 的运行时身份。
4. 活动模板五类齐全，且不含旧海洋叙事。
5. 旧记忆过滤不修改原始数组和数据库记录。
6. 自主对话提示包含选定日常话题、20–60 字与少旁白规则。
7. 海洋设定或超长模型输出触发确定性安全回退。
8. 归纳标签覆盖日常社会类别，普通对话不再统一显示为河道、灯火、花木或机关谜团。
9. 使用固定样本运行连续对话时，至少 85% 话题属于生计、人际或公共生活，0% 自主话题属于灯塔谜团。
10. 即使输入包含旧“异变、灯火装置、河道线索、花木线索”消息，实时速报也不得输出这些旧固定标题或悬疑化归纳；没有新事实时显示空状态。

## 非目标

- 本阶段不删除历史消息、记忆、旧赛事记录或研究日报。
- 本阶段不实现完整经济系统、婚姻生育、政府选举或人口增长。
- 本阶段不更换本地模型，不引入云模型回退。
- 本阶段不修改地图美术或每日活动/试炼岛状态机。
